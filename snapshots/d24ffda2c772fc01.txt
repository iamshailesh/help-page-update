Overview
The Execute workflow API allows you to automate workflow actions using tickets in ManageEngine Log360.
You can:
Fetch a list of available workflows
Retrieve template data for specific workflows
Execute workflows directly using a ticketing tool connection.
Fetch all available workflows
This API allows you to fetch the list of all available workflows configured in the product console.
Request URL
GET http://hostname:8095/RestAPI/v1/workflow/templates/list
NOTE
For the request URL, you can either use the IP address, or FQDN of the product server in place of hostname.
Request Header
Header name
Value
Mandatory
Description
Authorization
Bearer {{AuthToken}}
Yes
AuthToken generated from the API Settings page.
Example: Bearer abcd1234xyz
Response
The response will be a JSON object containing the following key/value pairs:
Parameter name
Description
workflow_list
A JSON array containing the list of all available workflows and their details in the product console.
message
Status of the API call to fetch all available workflows.
Executing the API using
cURL
Sample request
curl --location 'http://localhost:8095/RestAPI/v1/workflow/templates/list' \
--header 'Authorization: Bearer abcd1234xyz' \

Fetch template data for workflow
This API allows you to fetch detailed template data for a specific workflow.
Request URL
GET http://hostname:8095/RestAPI/v1/workflow/templates/details
Request Header
Header name
Value
Mandatory
Description
Authorization
Bearer {{AuthToken}}
Yes
AuthToken generated from the API Settings page.
Example: Bearer abcd1234xyz
Request Parameters
Parameter Name
Mandatory
Type
Description
template_id
Yes
Long
Template ID of the workflow whose template details needs to be fetched.
Response
The response will be a JSON object containing the following key/value pairs:
Parameter name
Description
workflow_details
A JSON array containing the block details of the workflow.
message
Status of the API call to fetch workflow template data.
Executing the API using
cURL
Sample request
curl --location 'http://localhost:8095/RestAPI/v1/workflow/template/details?template_id=1' \

Execute the workflow from ticket
This API allows you to execute a workflow in the product console using a ticket.
Request URL
POST http://hostname:8095/RestAPI/v1/ticket/workflow/execute
Request Header
Header name
Value
Mandatory
Description
Authorization
Bearer {{AuthToken}}
Yes
AuthToken generated from the API Settings page.
Example: Bearer abcd1234xyz
Request Parameters
Parameter Name
Mandatory
Type
Description
template_id
Yes
Long
ID of the workflow template to be executed.
template_name
Yes
String
Name of the workflow to be executed.
ticket_id
Yes
String
ID of the ticket from which the workflow is being executed.
tool_name
Yes
String
Name of the ticketing tool from which the workflow is being executed.
type
No
String
If the ticket is created from an alert, the value should be "alert".
custom_input
Yes
String
Workflow template block data (fetched from the previous Fetch Template Data for Workflow API).
Response
The response will be a JSON object containing the following key/value pair.
Parameter name
Description
workflow_details
A JSON array containing the block details of the workflow.
message
Status of the workflow execution.
