Overview
This page provides a comprehensive reference for writing custom functions in the product console using Python and Deluge scripting languages. It explains the required function structure, supported data types, input and output handling mechanisms, and logging capabilities available within the execution environment. The document also includes practical examples, default templates, and quick reference tables to help you build, test, and debug custom functions efficiently.
Python scripting reference
This section provides the Python scripting reference for writing custom functions in Log360 Cloud. Python functions run on the Zoho Hyper Functions (FaaS) platform using the
BasicIO
function type.
NOTE
Python is available in two versions:
2.7.15
and
3.9.16
.
Python functions support only
String
as the return type. Map return type is Deluge-only.
Python input parameters support only
String
data type.
Function Signature
Every Python custom function must define a runner function with two parameters:
Parameter
Description
context
Provides access to platform SDK features such as logging.
basicIO
Provides methods to read input parameters and write output data.
Copy
def runner(context, basicIO):
# Your function logic here
name = basicIO.getParameter("name")
basicIO.write("Hello " + name)
Default Code Template
When you create a new Python function, the editor pre-fills the following starter code:
Copy
def runner(context, basicIO):
context.log.INFO("Test Log")
basicIO.write("Hello")
BasicIO Methods
The basicIO object provides two methods to interact with input and output:
Method
Syntax
Description
getParameter
basicIO.getParameter(key)
Retrieves the value of the input parameter identified by key. The key must match a parameter name defined in the function configuration. Returns a string value.
write
basicIO.write(data)
Writes data to the function output. This is what the function returns as its result. The data must be a string.
Sample: Reading input and writing output
Copy
def runner(context, basicIO):
name = basicIO.getParameter("name")
basicIO.write("Hello " + name + "...!!!")

Sample: Using log levels
Copy
def runner(context, basicIO):
context.log.INFO("Function execution started")
context.log.WARNING("This is a warning message")
context.log.SEVERE("This is an error message")
name = basicIO.getParameter("name")
context.log.FINE("Received parameter: " + name)
basicIO.write("Done")
Complete Example â Python Custom Function
The following example demonstrates a complete Python function that reads two input parameters, logs the execution progress, and writes a formatted output:
Copy
def runner(context, basicIO):
# Log the start of execution
context.log.INFO("Function execution started")
# Read input parameters
alert_id = basicIO.getParameter("alert_id")
severity = basicIO.getParameter("severity")
context.log.FINE("Processing alert: " + alert_id)
context.log.FINE("Severity level: " + severity)
# Build output
result = "Alert " + alert_id + " with severity " + severity + " processed successfully"
# Write output
basicIO.write(result)
context.log.INFO("Function execution completed")
NOTE (Python-specific)
The input parameters (alert_id, severity) must be defined in the function configuration before execution.
When testing, provide sample values for each parameter in the Execute panel.
Logs appear in the
Logs
tab of the execution output, while the result of basicIO.write() appears in the
Output
tab.

For complete Deluge scripting syntax, built-in functions, data types, and examples, refer to the official Zoho Deluge documentation:

String
