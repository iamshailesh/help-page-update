Overview
The Embed link feature in Log360 allows you to generate secure, external share links for specific dashboard tabs or individual widgets. This enables controlled, read-only access to selected security data without requiring users to log in to the Log360 console.
Each embed link can be configured with a specific time range, refresh interval, and expiry period to ensure controlled data access. Embed links can also be managed, edited, regenerated, or deleted at any time.
This page explains how to configure embed links for dashboards and widgets, and how to manage existing embed links.
