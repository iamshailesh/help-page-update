Overview
This page covers the prerequisites for deploying Log Processors, how to configure them, and the steps to add both primary and additional Log Processors.
NOTE
It is recommended to configure a minimum of three log processors to ensure stability.

After creating a Log Processor cluster, ensure the following requirements are met:
To start a Log Processor in a cluster, the minimum number of Processors required to bring the cluster online must be running. The required count is calculated as:
Minimum Processors = (Total number of Processors / 2) + 1
NOTE
For example, when there are three Log Processors in the deployment, a minimum of two must be running for the cluster to start.
Available disk space must be greater than 15 GB.

Adding additional Log Processors
NOTE
When adding an additional Log Processor in a Log360 Scalability deployment, there is no need to configure the common database separately. The additional Log Processor automatically retrieves the database connection details from the Primary Log Processor and connects to the same external (common) database.
Please ensure that the Primary Log Processor is already configured to use the external (common) database before adding the additional Log Processor.
