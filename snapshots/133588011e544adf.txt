Overview
This page lists the AWS reports available in the product to help monitor login behavior, authorization failures, IAM activity, network and VPC changes, S3 and file transfers, load balancer performance, Route53 configurations, and security token operations. These reports assist administrators in tracking successful and failed events, identifying configuration changes, auditing content access, and analyzing operational and security trends across AWS resources.
