Overview
Synology NAS File Monitoring reports provide visibility into file and folder activities occurring within monitored Synology NAS systems. These reports help administrators track integrity-related actions such as file creation, modification, deletion, access events, permission changes, and movement operations.
By presenting activity details based on servers, these reports support auditing, troubleshooting, and detection of unauthorized or unexpected changes within Synology NAS storage environments.
