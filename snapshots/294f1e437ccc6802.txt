Jira Service Desk On-Demand
Jira Service Desk On-Demand
Jira Service Desk On-Demand is a cloud-based help desk software which, when integrated with Log360 Cloud, empowers IT and security teams to enhance their incident response capabilities. This integration helps detect threats and vulnerabilities in real time, respond to incidents without switching between tools, and streamline operations by managing alerts and tickets directly within Jira Service Desk.
Actions Supported
Two-way synchronization
Disable log collection
Disable ticketing tool notification
Export incident
Before you begin:
Sign up and create an account in Log360 Cloud if you haven't already.
Steps to Integrate Log360 Cloud with Jira Service Desk On-Demand
Log in to
Jira
as an admin.
Download the Log360 Cloud application from the Atlassian Marketplace.
In the top navigation bar, under the
Apps
drop-down, click Log360 Cloud.
In the page that opens, click the
Integrate Now!
button.
Access the API Console for your respective Log360 Cloud data center. Refer to the table below to find the data center corresponding to your Log360 Cloud account.

Click the

tile, and create a new self client.
Copy the
Client ID
and
Client Secret ID
values, then return to the Jira console and paste them into the respective input fields.
Back in the API Console page, go to
Generate Code
, copy the scopes below, and paste them in the
Scope

Copy to Clipboard
"logs360cloud.accounts.READ, logs360cloud.alertprofiles.read, logs360cloud.devices.update, logs360cloud.incidents.export.create, logs360cloud.incidents.export.read, logs360cloud.incidents.update, logs360cloud.ticketingtool.configuration.read, logs360cloud.ticketnotification.update."
Click
Create
.
When the
Access Code
pop-up appears, click
Copy
to copy the access code, then return to
Jira
, paste it in the respective input box, and click
Next
.
Log360 Cloud will be successfully configured. The configuration details can be edited if needed.
Admins will have access to the configuration page by default. Associated users will only have access to the
Tickets
window.
To associate users, open the
Associate Users
tab in the configuration section and associate the Jira users.
Exporting an Incident
Prerequisite
: A Jira ticket must be raised from a
Log360 Cloud
incident.
Go to the
Log360 Cloud
tab in the Jira ticket's right panel and click
Export Incident
.
Click
Export
to confirm.
The incident will be exported as a PDF from Log360 Cloud and downloaded automatically.
Disable Ticketing Tool Notification
Prerequisite
: The Jira ticket must be raised from the
Alerts
tab Log360 Cloud.
Go to the
Log360 Cloud
tab in the ticket's right panel and click
Disable Ticketing Tool Notification
.
Click
Yes
in the confirmation box.
The notification profile will be successfully disabled.
Disable Log Collection
Go to the
Log360 Cloud
tab in the ticket's right panel and click
Disable Log Collection
.
Enter the
Device Name
exactly as it appears in Log360 Cloud to disable log collection for that device.
The device will be successfully disabled for log collection.
