Automatic configuration
Object level auditing must be configured to ensure that events are logged whenever any Active Directory object related activity occurs. On providing Domain Admin credentials, Log360 Cloud automatically configures the required object level auditing for Active Directory auditing.
Note
Automatic object level auditing configuration is not done without the users consent.
Configuring object level auditing requires the "Manage auditing and security log" privilege, which should be assigned via the security policy.
To configure object level auditing:
Login to
Log360 Cloud
web console.
Go to
Reports → GPO Management → GPO History
.
In GPO History, click on
Object level auditing and Audit policy needs to be configured to view related reports → Know More
.
In the
Object level auditing needs to be configured to view related reports
message, click on
Configure
.
In the user consent warning, click
Confirm
to configure object level auditing.
You can also configure object level auditing with the following steps:
Login to
Log360 Cloud
web console.
Go to
Domain Settings
and click on
Object Level Audit: Configure
.
In the user consent warning, click
Confirm
to configure object level auditing.
