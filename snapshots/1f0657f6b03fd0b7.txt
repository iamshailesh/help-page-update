Overview
The manage alerts section provides an overview of all configured alert profiles along with their severity, associated log sources, and notification settings. Based on the
Created By
type, alert profiles can be edited, deleted, copied, or toggled on/off. Similarly, few alert profiles, however, can only be enabled, disabled, or duplicated and cannot be edited or deleted.

Enable/disable an alert profile
Enabling an alert profile
Click on the enable
icon present in the ribbon to enable the alert.
The alert is now enabled, and a confirmation pop-up briefly appears.
Disabling an alert profile
Click on the disable
icon present in the ribbon to disable the alert.
The alert is now disabled, and a confirmation pop-up briefly appears.
Delete an alert profile
Click on the
Delete
icon
under the
Actions
column to delete the alert.
A
Delete Action
pop-up appears for confirmation. Click on the checkbox and
Yes
to proceed.
Once completed, a success confirmation pop-up appears.
NOTE
Only applicable alert profiles based on the
Created By
type can be deleted. Similarly the rest of the types can only be enabled, disabled, or copied.
Edit an alert profile
Click on the
Edit
icon
under the
Actions
column to modify the respective alert profile.
You will be taken to the
Edit Alert Profile
module. Make the necessary changes to the criteria, severity, or notification settings, and click on
Update
.
Image 5: Edit alert profile via manage alert profiles module
Upon successful completion of the action, the below pop-up appears, and the alert is saved instantly, and you are redirected back to the Manage Alerts module with the updated alert listed.
Clone an alert profile
Click on the
Clone
icon
under the
Actions
column to duplicate the respective alert profile.
The alert is instantly duplicated, and you will be instantly taken to the
Add Alert Profile
module where you can edit the cloned alert profile based on your requirements and save that version on the cloned alert profile.

Filtering alert profiles
You can filter alert profiles in the following ways:
Based on status (enabled/disabled)
Use the filter option above the alerts list to view only enabled or only disabled alert profiles.
Image 7: Filtering alert profiles via manage alert profiles module
This helps you quickly identify active alerts versus those that are turned off.
Image 8: Filtering alert profiles via manage alert profiles module
Calendar-based filtering
Click on the calendar icon in the filter options.
Image 9: Filtering alert profiles for a time range
The action opens a calendar view along with predefined time ranges for you to choose from. You can also view the count of all triggered alerts based on the time range.
Image 10: Filtering alert profiles for a time range
Click on any of the predefined time ranges available that best suits your requirement.
Click on Custom range and enter a number in the box provided to represent the past number of daysâ worth of alerts you wish to view.
Click on
Apply
.
Upon completion, the alerts list will continue to display all available profiles. However, the alert counts will be filtered and updated based on the selected time range.
More Options
Click on the More Options icon as highlighted below to view the Import and Export actions.
Image 11: More options for managing alert profiles
Import alert profiles
Click on the
Import
option in the options list.
Browse and select the file that contains the alert profiles you wish to import.
If the imported alert profile matches an existing one, you will be prompted to overwrite the existing profile. Select the required profile and click
Import
.
Export alert profiles
Select the required alert profiles using the checkbox(es).
Click on the
Export
option in the options list.
NOTE
Default, extension-based and Rule-based alert profiles cannot be exported.
