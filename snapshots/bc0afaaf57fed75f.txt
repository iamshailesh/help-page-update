Overview
Connections are invoked by integrations that require communication with an external service. Instead of requiring repeated authentication, modules such as Applications, Custom Widgets, and Custom Functions automatically use the existing connection you have configured. This ensures secure and seamless access to the external service.
This section explains how connections are invoked within the Applications, Custom Widgets and Custom Functions modules.
Invoking connections from Applications
In the product console, go to the
Settings
tab and select
Admin
.
Under
Log Source Configuration
, select
Applications
.
In the
Applications

Other Applications
tab.
Select a
Log Source Type
for which you want to create a connection.

Figure 3: Selecting a connection

Create Connection.

Creating a connection.

Click
