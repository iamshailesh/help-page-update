Overview
This page lists the VMware ESXi reports available in the product for monitoring user logon and logoff activity, hypervisor events, system-level changes, and virtual machine operations. These reports help administrators track authentication behavior, identify configuration changes, and monitor VM lifecycle events across the virtual infrastructure.
