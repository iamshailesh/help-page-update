Overview
The Tags section lets you manage all the tags created for log search in Log360. Tags help you categorize and quickly identify logs that match specific queries. From this section, you can view, edit the criteria, or delete existing tags.
Each tag comprises:
Criteria: The query that is associated with the tag to filter and group relevant logs.
Notes: Additional information provided by the user to specify the purpose or context of the tag for future reference.
To create a new tag, refer to the
Tagging Tool
.
