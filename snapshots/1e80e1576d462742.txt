Overview
By creating and managing tags in ManageEngine Log360 you can bookmark important logs and complex search queries using tags. Tags and their associated notes support only alphanumeric characters. While any user can add notes to a tag, editing tag criteria is restricted to the user who created the tag and users with
admin privileges
in the product.
This page explains how to create, edit, search, and delete tags for efficient log analysis.
Use cases
Reuse complex searches:
Save frequently used search queries as tags and retrieve them instantly without re-entering multiple criteria.
Search across multiple log sources:
Associate logs from different sources (such as UNIX, Windows, or application logs) with a single tag and fetch them quickly when needed.
Add notes for future reference:
Include troubleshooting tips or observations with a tag to help users understand the purpose of the tagged logs during future analysis.

Deleting a tag
NOTE
Deleting a tag is permanent and cannot be undone. Once deleted, the tag name and its associated criteria are permanently removed from the system.
If a deleted tag was used in saved searches or search history:
The saved search or history entry will still be available.
The system does not distinguish between a deleted tag and a regular search keyword.
When the search is executed, the tag name is treated as a normal text/string query instead of a predefined tag reference. As a result, the original tag criteria are not applied, and the search behavior defaults to standard keyword matching.
Log in to the product console.
