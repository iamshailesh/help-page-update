Overview
A Access Gateway Cluster acts as a secure entry point for logs from external sources. It
masks the identity of internal systems and forwards incoming log data to internal Log
Processors, ensuring secure log collection. This deployment enhances perimeter security by
isolating external agents from the core system.
This page explains how to configure Access Gateway Cluster.
