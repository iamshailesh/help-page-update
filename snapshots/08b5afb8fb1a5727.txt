Configuring McAfee Solutions
Log360 Cloud collects log data from McAfee solution and presents it in the form of graphical reports. For the solution to start collecting this log data, it has to be added as a threat source.
To configure McAfee in Log360 Cloud, please follow the steps below.
Configure HTTPS in Log360 Cloud.
Enable the required TLS port.
Settings > System Settings > Listener ports
Configure your McAfee ePO server to use the newly created syslog server.
Add a new registered server and select
Syslog
for the type of server.
Enter the IP address or host name of the Log360 Cloud Agent server..
Enter <Any port that the Log360 Cloud agent server is listening to> for the port number.
Click on
enable event forwarding
.
Click on
test connection
. A Syslog connection success message will be displayed.
Click on
save
.
