Overview
Zia Insights is an AI-powered capability that delivers contextual security insights by analyzing logs, alerts, and incidents. These insights help interpret security activity, identify impacted entities, map observed behavior to the MITRE ATT&CKÂ® framework, and determine recommended response actions.
This page explains how to invoke Zia Insights from the Search, Alerts, and Incidents modules.
Invoking Zia Insights from Search
In your account, go to the
Search
tab.
Perform a search query using either the basic or advanced mode.
NOTE
Refer to this
video
to learn how to perform log searches.
In the search results, hover over a specific log entry.
Click on the
icon on the top-right corner of the log entry to view insights generated by Zia.

Zia will process the selected log and display contextual insights, including a summary, associated MITRE ATT&CKÂ® techniques (if applicable), and suggested mitigation steps.

Invoking Zia Insights from Alerts
In your account, go to the
Alerts
tab and select Alerts.
Select an alert from the list.
Click on the
icon displayed at the top-right corner to generate Zia Insights.
Figure 3: Invoking Zia Insights from Alerts
Insights provided by Zia Insights for Alerts
For alerts, Zia Insights provides contextual summary, attack timeline, relevant MITRE ATT&CKÂ® techniques (if applicable), and mitigation steps based on the alert data.

Alerts
