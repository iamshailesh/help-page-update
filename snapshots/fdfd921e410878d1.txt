The
Application Insight
tab provides visibility into the application usage of the client machines and users in your network. This analytics dashboard also provides an option to compare and analyze application usage trends over different time periods. The application usage can be visualized based on the download size, upload size, and request count.
How to track application usage using Log360 Cloud?
Navigate to Cloud Protection > Application Insight.
Select a time period for which you want to view the data from the calendar at the top right corner.
You can view the following insights in the form of intuitive graphs:
Total Traffic Trend
Top Cloud Apps by Request
Top Attempted Banned Apps
Top Shadow Cloud Apps by request
Top Cloud Apps by Download Size
Top cloud Apps by Upload Size
