Overview
This page explains how to install and uninstall ManageEngine Log360 on Windows and EventLog Analyzer on Windows and Linux platforms. It guides you through the installation process, including selecting the installation type and completing the setup.
Note
If the application is installed on a domain-joined machine, it automatically discovers the domain and adds up to five Windows Server devices that respond first to a broadcast query. These devices can be deleted manually and will not be re-added automatically.
