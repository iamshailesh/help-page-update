Overview
Windows Cluster reports under File Integrity Monitoring provide centralized visibility into file and folder activities across Windows failover cluster nodes. These reports help administrators monitor integrity-related events such as file creation, modification, deletion, access attempts, permission changes, and ownership updates within clustered environments.
By correlating activities across cluster nodes and shared storage, these reports support compliance auditing, forensic investigations, and detection of unauthorized or suspicious changes in Windows Cluster infrastructures.
