Errors in gateway server communication or configuration are displayed under
Settings > Configurations > Cloud Protection Settings > Server > Gateway Servers
column. The potential gateway server errors you may encounter are listed below along with the follow-up actions to troubleshoot each error.
Error code
Error message
Reason for error
Follow-up action
600005
Update Gateway Server
The gateway server version is outdated, preventing access to new features. Performance will remain unaffected.
Update the gateway server by following the steps found
here
.
600009
Sync blocked due to Gateway Server version mismatch
The gateway server version is outdated, preventing access to new features and configuration sync updates. The gateway server will perform minimal functions only.
Update the gateway server by following the steps found
here
.
600006/600010
Failed to communicate with the Log360 Cloud-Cloud Protection server
The gateway server's attempts to communicate with the Log360 Cloud-Cloud Protection server failed.
To resolve communication issues, try the following steps: In the machine where the gateway server is installed, access the Log360 Cloud-Cloud Protection server url via your browser.

Gateway Server Access Key regenerated
The Gateway Server Access Key has been regenerated.
Update the Gateway Server Access Key by following the steps found
here
.
600105
Low disk space
The machine running the gateway server has less than 2GB of free space. Cloud app auditing will be stopped until the issue is resolved.
To resolve the issue, free up disk space, or add additional space in the machine running the gateway server.
This will take certain time to reflect in gateway server. For immediate effect kindly restart the gateway server.
600202/600203
Failed to start proxy unit/Proxy unit stopped
The proxy unit within the gateway server could not be started.
For assistance in resolving this issue, please write to us at
support@log360cloud.com
.
600204
Proxy unit port unavailable
The port used by the proxy unit is unavailable.
By default, the proxy unit uses port 8200.
To resolve the issue, try the following steps:
Check if the port is occupied by another process and resolve it.
(OR)
Change Gateway server port to any other port number
To change another port:
Go to
Settings > Configurations > Cloud Protection Settings > Server > Gateway Servers
.
Click the edit icon next to the desired gateway server.
Edit the Port value.
Click Next to review the gateway server details.
Click Update.
