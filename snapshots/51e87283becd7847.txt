Overview
Roles define the set of permissions assigned to a user or a group of users in the product console. They determine what actions a user can perform and what data they can access. By creating and managing roles effectively, you can ensure that each user has the appropriate level of access, maintaining both operational efficiency and data security. This page elaborates on how to create new roles and manage existing ones.
Creating a role
In your account, navigate to the
Settings

Under
Admin Settings

The available permissions are grouped under these tabs:
Home, Reports, Compliance, Search, Security, Correlation, Alerts, Settings,

Select the checkbox beside a tab to grant all permissions under that tab.

Allow users to view, create, and manage dashboards.
View the Log Sources:
Assign permissions to view device, application, and file integrity monitoring logs.

Allow viewing, creating, and scheduling of compliance reports.

General
to assign all compliance permissions.
Figure 8: Configuring permissions in the Compliance tab

Allow or restrict the ability to search collected logs.
Figure 9: Configuring permissions in the Search tab
Security
Security

Activity Monitoring

Alerts

.

custom log parsing rules

tags
