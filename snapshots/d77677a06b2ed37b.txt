Overview
In ManageEngine Log360, profiles let you define which device groups are used to populate the productâs modules. You can select from the available device groups to create profiles, but only one profile can be set as the default. If any profile is set as the default, it will be reflected only for that user.
The devices included in this default profile determine the logs displayed across the Dashboard, Reports, and other modules, forming the foundation for log analysis within the product. This provides consistent, device group-specific visibility without requiring manual filtering in each module.
NOTE
If no profiles are created, all device groups are considered as the default by the product.

You can also select the checkbox

Setting a default profile
The
default profile
defines the device groups on which the productâs modules are based. Only one profile can be set as the default at a time.
To set a profile as the default:
In the
Profiles
page, click the icon corresponding to the desired profile.
In the confirmation pop-up, click
Yes
.
NOTE
Default profiles cannot be edited or deleted.
Editing a profile
In the Profiles page, click the
icon corresponding to the profile you want to modify.
Figure 6: Editing a profile
In the

NOTE
The View Name cannot be modified.
Figure 7: Updating device groups
You can also select the checkbox
Set this view as default profile

Click
Update
to save the changes.
