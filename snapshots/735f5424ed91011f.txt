Overview
The reports module provides a centralized view of all predefined and custom reports generated from logs collected across servers, network devices, security appliances, cloud services, applications, and storage platforms.
These reports help
users
review security events, monitor operational activity, investigate incidents through raw log drill-downs, and meet regulatory compliance requirements. Reports can be accessed from the
Reports
tab in the product console, where data can be filtered, analyzed, and exported based on various log attributes.
Available Reports:
The product provides a comprehensive set of predefined reports categorized by device types, operating systems, applications, databases, cloud platforms, and security solutions. These reports help administrators and security teams monitor activity, analyze trends, detect anomalies, investigate incidents, and meet auditing and compliance requirements across on-premises, hybrid, and cloud environments.
Each report category listed below contains multiple detailed reports that offer drill-down visibility into events, user actions, traffic patterns, configuration changes, and security threats.
